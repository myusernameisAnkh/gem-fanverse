# 五分钟课堂展示路线

## 0:00—0:40｜先讲清楚这个网站想解决什么

“我想把应援网站做成一个可以探索和参与的小宇宙。它既帮助初次接触邓紫棋的人认识音乐，也让粉丝表达自己的热爱。”

展示首页真实舞台照片、角色贴纸和导航。说明这是非官方课程设计。

## 0:40—1:35｜展示信息组织和检索

进入作品星球，搜索“光年”，清空搜索后切换“治愈”心情。收藏一首歌，再打开“我的收藏”。进入作品详情，展示官方聆听入口。

说明：作品资料和程序逻辑分开存放，新增作品不用重写交互逻辑。心情分类是本站编辑设计，并非官方分类。

## 1:35—2:15｜展示内容可信度

切换歌词卡；进入时间轴，筛选“新章”；在时间轴上指出资料出处。打开一帧舞台照片，用左右键切换，展示原图作者和许可。

说明：真实照片与 AI 同人插画分别标明，本站感想与歌词短摘分别呈现。

## 2:15—3:15｜让互动有一个可带走的结果

点亮几次荧光棒，做一次每日打卡。切换应援卡造型，输入自己的昵称，下载 PNG 应援卡。

说明：这里展示点击事件、日期判断、浏览器持久化和 Canvas 图片合成。计数属于当前浏览器。

## 3:15—4:10｜让同学参与

打开五题小挑战，邀请同学回答一题，展示答案解释和资料来源。完成后展示得分与电子徽章下载。

## 4:10—5:00｜展示留言与手机适配

提交一条本机留言，刷新后证明仍然存在。若已启用 giscus，用手机打开网站，展示共享留言；若未启用，明确说明本机表单与跨设备评论的区别。

切换深色主题、折叠手机导航，结束展示。

## 展示前准备

- 先在实际使用的电脑浏览器打开 GitHub Pages 地址，检查图片与应援卡下载。
- 需要展示共享留言时，提前完成 `config.js` 配置和两台设备验证。
- 网络环境不支持官方视频时，展示本地图片、搜索和 Canvas 功能；音视频入口仍保留官方链接。
- 截图或录屏用于课程提交时，避免包含 GitHub 登录页和账号敏感信息。
